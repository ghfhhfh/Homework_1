Задание 1: Поведение элементов по умолчанию

Заметки сталкера:
• Блочные элементы (h1, p, div) занимают всю доступную ширину строки. Каждый следующий блочный элемент начинается с новой строки.
• Линейные элементы (img, a, span) занимают только то место, которое необходимо для их содержимого. Они выстраиваются друг за другом в одну строку.

Задание 2: Преобразование элементов через display

Заметки сталкера:
• С помощью свойства display: inline мы заставили абзацы потерять свои блочные свойства и встать в ряд.
• С помощью display: block картинка начала вести себя как блок: перенеслась на новую строку и не пускает никого рядом с собой.
